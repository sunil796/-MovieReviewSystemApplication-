# Movie Review System

A Java backend project organized around authentication, user management, security, and service/repository layers.

## 🧰 Project Areas

The repository contains components for:

- Authentication controller
- Login and registration DTOs
- User and role entities
- User repository
- Authentication service
- Spring Security configuration
- JWT utility
- Application configuration

## 🏗️ Architecture

```text
Controller
    ↓
Service
    ↓
Repository
    ↓
Entity / Data Store

Security components
    └── Authentication + JWT support
```

## 🔐 Security

The project includes dedicated security components such as:

- `SecurityConfig`
- `JwtUtil`
- Authentication service
- Login / registration request and response DTOs

## 📌 Purpose

This project is part of my Java backend portfolio and demonstrates backend application structure, authentication concepts, DTO usage, service/repository separation, and Spring Security-related components.
